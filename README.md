# Rock Paper Scissors App

A simple Android application that allows users to play the classic Rock Paper Scissors game against the computer.

## 📱 About the Project

Rock Paper Scissors is a beginner-friendly Android game developed using Android Studio.

The user selects Rock, Paper, or Scissors, and the application generates a choice for the computer. The app then compares both choices and displays the game result.

## ✨ Features

- 🎮 Play Rock Paper Scissors against the computer
- 🪨 Rock selection
- 📄 Paper selection
- ✂️ Scissors selection
- 🤖 Computer-generated choice
- 🏆 Displays the winner
- 🔄 Simple and interactive gameplay
- 📱 User-friendly interface

## 🛠️ Technologies Used

- Java
- XML
- Android Studio
- Android SDK

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or start an emulator.
5. Click the **Run ▶️** button.
6. Select Rock, Paper, or Scissors to play.

## 🎯 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- If both choices are the same, it is a draw.

## 🎓 Purpose

This project was created to practice basic Android development concepts, user interaction, event handling, and game logic.
